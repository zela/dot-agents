# D2 render

The `.d2` file is the source. The rendered SVG is its build output, and the two are committed together as `<name>.d2` and `<name>.svg`. The SVG embeds its fonts, needs no JavaScript, and switches theme with the reader's color scheme, even inside an `<img>` tag. The shared rules are in [SKILL.md](SKILL.md).

## Steps

1. **Write the source.**
   - Start with `direction: down`.
   - Use containers for boundaries: `backend: Backend { api; worker }`. Split a large picture into `layers`.
   - Use the shape that names the thing: `shape: cylinder` for a store, `shape: sequence_diagram` for a call sequence, `shape: sql_table` for a schema, `shape: class` for a UML class.
   - Name the source files in a comment at the top of the file.
2. **Validate and format.** Run `d2 validate <name>.d2`, then `d2 fmt <name>.d2`.
3. **Render.**

   ```bash
   d2 --layout=elk --theme=0 --dark-theme=200 --pad=24 --omit-version <name>.d2 <name>.svg
   ```

   - `--layout`: `elk` is the default choice. `tala` is built for software architecture and picks its own direction. If TALA output shows a watermark or a license notice, use `elk`. `dagre` is D2's built-in default.
   - `--theme` and `--dark-theme` pick the light and dark themes. `d2 themes` lists them.
   - `--pad=24` replaces the default 100 px margin.
4. **Check the render** with the shared check.
5. **Re-render after each source edit**, so that the committed SVG matches the `.d2` file.

## Other outputs

- **ASCII for Markdown:** `d2 --layout=elk <name>.d2 <name>.txt`. Put the result in a code block. With `direction: down` it stays narrow. ASCII output is a beta feature and needs the ELK or TALA layout.
- **Animated steps:** define `steps` in the source and render with `--animate-interval=1200`. The SVG shows each board for 1.2 seconds.
- **PNG, PDF, PPTX, GIF:** change the output extension. PDF and PPTX put one board on each page or slide.
- **Live editing for the user:** `d2 --watch <name>.d2 <name>.svg` opens a browser preview that reloads on save. It runs until it is stopped, so suggest it to the user rather than run it.
- **Embedding:** `<img src="<name>.svg">` or `![](<name>.svg)` keeps the dark mode but drops tooltips and links. An inline `<svg>` keeps them. For several inline copies of one diagram in a page, render each with a different `--salt`.

`d2 play` uploads the file to the online playground at play.d2lang.com. Run it only when the user asks for it.
